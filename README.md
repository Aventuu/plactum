# Plactum

> El ojo que no se cierra.

Newsletter semanal de pago sobre inteligencia artificial para el mercado
colombiano (con expansión a LatAm proyectada). Ver `SPEC.md` para la
especificación completa del producto, marca y arquitectura.

## Desarrollo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Deploy: Vercel
- Pendiente de integrar: Supabase (suscriptores), MercadoPago (pagos), Resend (email)
